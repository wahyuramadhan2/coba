Soal 1 — Penjumlahan Matriks

A =
23
14

23

Penjumlahan matriks dilakukan dengan menjumlahkan elemen-elemen yang bersesuaian (posisi sama).

Langkah:

A + B = [aij + bij]

= [ (2+5), (3+1) ; (1+2), (4+3) ]

Jawaban: A + B =
74
37

Soal 5 — Determinan Matriks 2×2

Hitung determinan dari matriks:

Pembahasan:

Rumus determinan 2×2:

det(A) = |A| = ad - bc

Soal 7 — Determinan Matriks 3×3

A =
123
456
780

Metode Sarrus / Ekspansi Kofaktor baris 1:

det(A) = a(ei−fh) − b(di−fg) + c(dh−eg)
Langkah (Ekspansi baris 1):

Soal 8 — Sistem Persamaan Linear (Metode Matriks Invers)

Selesaikan SPL berikut menggunakan metode invers matriks:

2x + 3y = 7
4x + y = 9

Pembahasan:

Bentuk matriks: AX = B, maka X = A-1B

Langkah 1: Identifikasi matriks

A = [2,3 ; 4,1], X = [x ; y], B = [7 ; 9]

Langkah 2: Hitung det(A)

det(A) = (2)(1) - (3)(4) = 2 - 12 = -10

Langkah 3: Hitung A-1

A-1 = (1/-10) × [1, -3 ; -4, 2]

= [-1/10, 3/10 ; 4/10, -2/10]

= [-0.1, 0.3 ; 0.4, -0.2]

Langkah 4: X = A-1 × B

x = (-0.1)(7) + (0.3)(9) = -0.7 + 2.7 = 2

y = (0.4)(7) + (-0.2)(9) = 2.8 - 1.8 = 1

Jawaban: x = 2, y = 1

Soal 9 — Invers Matriks 3×3

Tentukan invers dari matriks:

A =
101
021
111

Pembahasan:

A-1 = (1/det(A)) × adj(A)
Langkah 1: Hitung det(A)

= 1[(2)(1)-(1)(1)] - 0[(0)(1)-(1)(1)] + 1[(0)(1)-(2)(1)]

= 1[2-1] - 0[0-1] + 1[0-2]

= 1 - 0 + (-2) = -1

Langkah 2: Hitung matriks kofaktor

C11 = +(2·1 - 1·1) = 1

C12 = -(0·1 - 1·1) = 1

C13 = +(0·1 - 2·1) = -2

C21 = -(0·1 - 1·1) = 1

C22 = +(1·1 - 1·1) = 0

C23 = -(1·1 - 0·1) = -1

C31 = +(0·1 - 2·1) = -2

C32 = -(1·1 - 0·1) = -1

C33 = +(1·2 - 0·0) = 2

Langkah 3: Adjoin = Transpose kofaktor

adj(A) = [1, 1, -2 ; 1, 0, -1 ; -2, -1, 2]T = [1, 1, -2 ; 1, 0, -1 ; -2, -1, 2]

Langkah 4: A-1 = (1/-1) × adj(A)
Jawaban: A-1 =
-1-12
-101
21-2

Soal 10 — Eigenvalue dan Eigenvector

Tentukan eigenvalue (nilai eigen) dari matriks:

A =
41
23

Pembahasan:

Eigenvalue diperoleh dari persamaan karakteristik:

det(A - λI) = 0
Langkah 1: Bentuk (A - λI)

A - λI = [4-λ, 1 ; 2, 3-λ]

Langkah 2: det(A - λI) = 0

(4-λ)(3-λ) - (1)(2) = 0

12 - 4λ - 3λ + λ² - 2 = 0

λ² - 7λ + 10 = 0

Langkah 3: Faktorkan

(λ - 5)(λ - 2) = 0

λ₁ = 5, λ₂ = 2

Langkah 4: Cari Eigenvector untuk λ₁ = 5

(A - 5I)v = 0 → [-1, 1 ; 2, -2][v₁ ; v₂] = 0

-v₁ + v₂ = 0 → v₂ = v₁

v₁ = [1 ; 1] (atau kelipatannya)

Langkah 5: Cari Eigenvector untuk λ₂ = 2

(A - 2I)v = 0 → [2, 1 ; 2, 1][v₁ ; v₂] = 0

2v₁ + v₂ = 0 → v₂ = -2v₁

v₂ = [1 ; -2] (atau kelipatannya)

Jawaban:
λ₁ = 5 dengan eigenvector [1 ; 1]
λ₂ = 2 dengan eigenvector [1 ; -2]
